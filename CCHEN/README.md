# Trader Edge Tracker - Landing Page

A futuristic, modern landing page for the Trader Edge Tracker trading journal application.

## 🚀 Quick Start

### Option 1: Using Node.js (Recommended)
```bash
npm run dev
```
or
```bash
node server.js
```

Then open your browser and go to: **http://localhost:3000**

### Option 2: Using Python
```bash
python -m http.server 8000
```
Then open: **http://localhost:8000**

### Option 3: Direct File Access
Simply open `index.html` in your browser (some features may not work due to CORS).

## ✨ Features

- **Animated Background Particles** - Dynamic floating particles
- **Trading Chart Visualization** - Animated candlestick chart
- **Animated Stats Counters** - Numbers count up on scroll
- **Smooth Scrolling** - Elegant navigation
- **Responsive Design** - Works on all devices
- **Dark Theme** - Professional trading aesthetic

## 🛠️ Requirements

- **Node.js** (for npm commands) - [Download here](https://nodejs.org/)
- OR **Python 3** (for Python server)
- Modern web browser (Chrome, Firefox, Edge, Safari)

## 📝 Notes

- The server runs on port **3000** by default
- All data is client-side only (no backend required)
- No external dependencies needed for the server (uses built-in Node.js modules)
